# 群友直连客户端 · 使用说明

欢迎来到服务器直连群！用它，双击一下就能连上服务器，不用学任何技术。

## 一、怎么开始
1. 双击打开 `EasyTierGroupClient.exe`，系统问「是否允许此应用更改设备」时点「是」。
2. 首次使用：展开窗口下方的「设置」，把管理员私发给你的**邀请码**粘进去，点「保存邀请码」。
3. 点「连接」。第一次连接如果弹出网络驱动安装窗口，点「允许/安装」。
4. 等几秒，看到托盘（右下角）出现绿色圆点、窗口显示虚拟 IP，就是连上了。
5. 完事。以后每次双击打开就自动连接，不用再填任何东西。

## 二、它自己会做什么
- 自动向你分配一个专属虚拟 IP，不用你填任何东西。
- 自动缩到系统托盘，不占任务栏。
- 托盘图标是「我要闹了」头像，右下角小圆点颜色代表状态：
  - 绿色 = 已连接
  - 橙色 = 连接中
  - 灰色 = 未连接（点一下图标选「连接」重连）
- 看不到图标？点任务栏右下角的 **^** 小箭头展开隐藏图标，把它拖到时钟旁边即可常驻。

## 三、常见问题
**Q：连不上怎么办？**
A：先看托盘图标是不是灰/红色，在窗口里点一次「连接」；还不行就重启客户端；再不行重启一次电脑（一般是驱动没装好）。

**Q：提示「人数已满」？**
A：同时在线最多 10 人，等别人下线后再连。

**Q：提示「邀请码无效」？**
A：核对是否复制完整，仍然不行就找管理员换码。

**Q：会占用我很多资源吗？**
A：不会，它很轻，后台静默运行。

**Q：是不是所有人都能连？**
A：只允许群成员连我们指定的一台服务器，且最多 10 人。不是群友连不上。

**Q：我访问的是你们本地电脑吗？**
A：不是。你连的是群里的专属服务器，不会碰到群主的个人电脑，放心。

**Q：需要安装驱动吗？**
A：第一次运行可能会弹窗询问是否安装网络驱动，请点「允许」，否则连不上。

## 四、重要提醒
- 请勿把你的客户端或账号分享给群外人。
- 客户端是给你访问服务器的，不要乱用它做其它事。
- 遇到问题直接找群主，不要自己乱改配置。
