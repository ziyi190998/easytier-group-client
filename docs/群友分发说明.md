# 群友分发说明（管理员操作手册）

> v1.0.3 起已**取消邀请码机制**：无需发码，把 exe 发给群友即可连。旧版邀请码清单 Excel 仅作历史存档。

## 分发清单
- `EasyTierGroupClient.exe`（76MB，GitHub Releases 下载，所有群友同一份）

## 教群友使用（一分钟）
1. 双击 `EasyTierGroupClient.exe`，系统弹 UAC → 点「是」。
2. 点「连接」。首次连接若弹出网络驱动安装窗口 → 点「允许/安装」。
3. 右下角托盘出现绿点头像、主界面显示虚拟 IP 即成功；之后每次双击打开点「连接」即可。

## 管理员日常
- 查看谁在线 / 池占用（部署文档有完整命令）：
  ```bash
  ssh -i astrbot.pem ubuntu@101.43.121.186
  curl -sk "https://127.0.0.1:11020/api/status?admin_key=$(grep ADMIN_KEY ~/easytier-ip-alloc/.env | cut -d= -f2)"
  ```
- 每个客户端凭本机自动生成的机器标识（machine_id）绑定租约：重连自动拿回同一 IP；换电脑/重装系统会换新标识（旧租约 90 秒自动回收）。
- 想让某人下线：无法按人吊销（无邀请码），可临时 `sudo docker compose restart` 重启 IP 服务（全员重连），或轮换组网口令（见部署文档）。

## 常见问题答复群友
- 连不上：窗口点「连接」重试；再不行重启电脑（一般是驱动没装好）。
- 弹「在线人数已满」：IP 池 101 个，等一会儿会自动重试。
- 找不到托盘图标：Win11 可能默认收进隐藏区，点任务栏右下角 **^** 箭头展开，把「我要闹了」头像图标拖到时钟旁即常驻显示。
- 电脑关机/退出客户端即自动释放 IP 和连接，无需其它操作。
