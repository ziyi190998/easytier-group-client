# 群友分发说明（管理员操作手册）

## 分发清单（每位群友两样）
1. `EasyTier群友客户端.exe`（76MB，仓库 `publish/` 目录，也可复制给所有群友同一份）
2. **个人邀请码**（16 位，一人一码，私发勿群发）

## 获取邀请码
```bash
ssh -i astrbot.pem ubuntu@101.43.121.186 "cat ~/easytier-ip-alloc/data/codes.json"
```
10 个码备注为 群友01~10。记录「码 → 群友」对应关系，便于日后吊销。

## 教群友安装（一分钟）
1. 双击 `EasyTier群友客户端.exe`，系统弹 UAC → 点「是」。
2. 展开左下「设置」，把邀请码粘进去 → 点「保存邀请码」。
3. 点「连接」。首次连接若弹出网络驱动安装窗口 → 点「允许/安装」。
4. 右下角托盘出现绿点、主界面显示虚拟 IP 即成功，之后双击 exe 就是自动连接。

## 常见问题答复群友
- 连不上：托盘点右键→连接 重试；再不行重启电脑（驱动没装好）。
- 弹「人数已满」：在线超 10 人，等别人下线。
- 弹「邀请码无效」：联系管理员核对/换码。
- 电脑关机/退出客户端即自动释放 IP 和连接，无需其它操作。

## 吊销某人的访问
```bash
ssh -i astrbot.pem ubuntu@101.43.121.186
vi ~/easytier-ip-alloc/data/codes.json   # 把对应码 revoked 改为 true
curl -sk -X POST -H "X-Admin-Key: $(grep ADMIN_KEY ~/easytier-ip-alloc/.env | cut -d= -f2)" \
  https://127.0.0.1:11020/api/admin/reload
```
吊销后该码最多 90 秒内被踢下线（心跳超时）。更彻底可同时轮换网络口令（见部署文档）。
